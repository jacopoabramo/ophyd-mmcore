Add `MMSystem`, which builds `ophyd-async` devices from a Micro-Manager configuration file or a `pymmcore-plus` core: `MMCamera`, `MMZStage`, `MMXYStage`, `MMShutter`, `MMStateDevice`, `MMDevice` and `MMConfigGroup`. `MMSystem` loads a file at `connect()`, keeping the devices a given core already holds under the same adapter, and adds a child for each device and configuration group of the core. Children can also be declared in a subclass of `MMSystem` with `Label` and `Property` annotations, and each device class can be built alone from a label and a core. `MMCamera` writes one `.zarr` store per physical camera through an `ophyd-async` path provider.

```python
scope = MMSystem("MMConfig_demo.cfg", path_provider=provider)
await scope.connect()
```
